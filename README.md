# Cargo Ships
Create a network of ships, similar to trains, but slower, bulkier, with integrated engines, and on water. Take advantage of offshore oil, and gain access to a personal boat vehicle. Just like with rails, you place water ways, ports, signal buoys...

## Important Notes About Version 2.1.0 and Above:
 - Cargo Ships 2.1.0 and above cannot migrate saves from version 1.1 and below. You must load and save the map in a recent version of Factorio 2.0 before loading it with 2.1.
 - Cargo Ships is now three separate mods. If you have Offshore Oil and Floating Electric Pole enabled in your map, you MUST install them manually before loading the map with 2.1.
 - [Cargo Ships](https://mods.factorio.com/mod/cargo-ships) : Ships, boats, waterways, bridges. Used to transport items and fluids across the water.
 - [Cargo Ships: Oil Rig](https://mods.factorio.com/mod/cargo-ships-oil-rig) : Oil rig, Offshore oil resource. Offshore oil spawns in the ocean and can be extracted with the Oil rig.
 - [Cargo Ships: Floating Electric Pole](https://mods.factorio.com/mod/cargo-ships-floating-electric-pole) : Electric pole that can be placed on water for long distance power grids.

## Features
 - 3 railed ships (tanker, cargo ship, small boat)
 - 1 vehicle boat (SHIFT + ENTER to board)
 - Water ways (rails), port (train stop), buoy and chain-buoy (rail signals), retractable rail bridge (makes crossing rails and water ways possible)
 - Oil rig (to pump offshore oil), floating electric pole (transmit but doesn't distribute electricity)
 - 8 technologies
 - Possibility to disable land oil
 - Mod API to add more types of ships
